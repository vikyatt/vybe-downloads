# VYBE

Light that moves with the beat and lyrics that come alive — synced to whatever is playing on Spotify. Free for Mac and Windows.

**Website, install guide and FAQ: https://vybelights.vercel.app**

## Download
- **Mac:** [VYBE.dmg](https://github.com/vikyatt/vybe-downloads/releases/latest/download/VYBE.dmg) — macOS 13 or later
- **Windows:** [Microsoft Store](https://apps.microsoft.com/detail/9N6FRLKR9KG6) or [VYBE-Setup.exe](https://github.com/vikyatt/vybe-downloads/releases/latest/download/VYBE-Setup.exe)

## Problems or ideas?
[Open an issue](https://github.com/vikyatt/vybe-downloads/issues/new) and describe what happened.

VYBE is an independent app and isn't affiliated with Spotify. [Privacy policy](https://vybelights.vercel.app/privacy.html)
